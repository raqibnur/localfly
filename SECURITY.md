# Security

Localfly forwards network traffic, so security reports matter.

Please **don't open a public issue** for a vulnerability. Report it privately through GitHub instead: on the repository's **Security** tab, choose **Report a vulnerability**. You should hear back within a week.

When you turn a tunnel on, anyone who has its address can reach that app. Only expose what you mean to share, and keep a secret set on self-hosted relays.
